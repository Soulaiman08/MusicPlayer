# Lyrics Analysis

## Lyrics Types
1. **Embedded lyrics** (USLT/SYLT in ID3 tags)
2. **LRC files** (synchronized lyrics)
3. **TXT files** (plain text lyrics)
4. **Online lyrics** (Google search)

## Lyrics Features
- Sync/highlight current line
- Auto-scroll to current position
- Click-to-seek (tap line to jump)
- Offset adjustment (time sync)
- Desktop floating lyrics overlay
- Status bar lyrics display
- Lock screen lyrics

## Desktop Lyrics Settings
- Font size (default: 16)
- Alpha/transparency (0.0-1.0)
- Preset colors (10 options)
- Custom normal color
- Custom highlight color
- Lock position toggle
- Drag to reposition

## Status Bar Lyrics
- Enable/disable
- Click to play/pause
- Gravity: Center or Left
- Content: Song name or Lyrics
- Position: X/Y offset (0-100%)
- Width (0-100%)
- Font size (0-100%)
- Alpha (0-100%)
- 10 preset colors

## Lyrics Search
- Local: Browse .lrc files (ActivityLrcBrowser)
- Online: Google search (ActivityLrcNetSearch)
- Clipboard detection for lyrics URLs
- Bind lyrics to track

## Lyrics Management
- ActivityLyricList: List/search/bind/delete lyrics
- Related lyrics (for current song)
- All lyrics (full library)
- Search by title
